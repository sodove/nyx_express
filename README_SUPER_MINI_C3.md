# VESC Express на RadioStack ESP32-C3 Super Mini

## Пайка

Прошивка использует следующий pin map платы с изображения:

| Плата | Куда подключить | Назначение |
|---|---|---|
| GPIO1 / A1 | TXD трансивера | CAN TX |
| GPIO0 / A0 | RXD трансивера | CAN RX |
| 5V | VCC TJA1051 | питание CAN-драйвера |
| 3V3 | VIO TJA1051T/3 | уровни логики ESP32 |
| GND | GND трансивера | общий провод |
| CANH трансивера | CANH VESC-шины | дифференциальная линия |
| CANL трансивера | CANL VESC-шины | дифференциальная линия |
| GPIO10 | DIN первого WS2812 | данные ленты |
| 5V внешнего БП | +5V ленты | питание ленты |
| GND внешнего БП | GND ленты и GND платы | общий провод |

Для TJA1051T/3 в корпусе SO8 распиновка такая: pin 1 TXD, pin 2 GND, pin 3 VCC=5V, pin 4 RXD, pin 5 VIO=3V3, pin 6 CANL, pin 7 CANH, pin 8 S=GND. Низкий уровень S включает Normal mode. Поставить 100 nF между VCC и GND рядом с микросхемой. CANH/CANL не подключать непосредственно к GPIO ESP32.

Если на корпусе нет суффикса `/3` (например TJA1051T или TJA1051T/E), pin 5 не является VIO, а логические уровни привязаны к 5V. Такой вариант нельзя напрямую соединять с RXD ESP32; нужен преобразователь уровней или трансивер TJA1051T/3. У TJA1051T/E pin 5 — EN, это другая версия.

На распространённом модуле с маркировкой `NC, S, CANL, CANH, RX, TX, GND, VCC` используется именно обычный TJA1051: `NC` оставляется неподключённым, `VCC` питается от 5V, `S` подключается к GND. Для ESP32-C3 безопасно поставить делитель на линии `RX` модуля: RX модуля -> 10 kΩ -> GPIO0, а GPIO0 -> 20 kΩ -> GND. Линию GPIO1 -> TX модуля для гарантированного 5-вольтового VIH лучше пропустить через 74AHCT1G125/74HCT125; без него на коротком столе часто работает, но это не гарантируется даташитом.

Для WS2812B поставьте последовательно в DATA резистор 330–470 Ом около первого пикселя. При питании ленты от 5 V желательно использовать 74AHCT1G125/74HCT125 как преобразователь уровня 3.3 V -> 5 V. На входе питания ленты поставьте электролит 470–1000 мкФ. Ленту не питать от вывода 3V3; для длинной ленты используйте отдельный 5 V БП с запасом по току.

Терминация CAN 120 Ом должна быть только на двух физических концах шины. Если модуль трансивера уже содержит 120 Ом, проверьте, что он действительно находится на конце линии.

UART остаётся доступным на TX=GPIO21 и RX=GPIO20: подключать перекрёстно TX платы -> RX внешнего устройства, RX платы -> TX внешнего устройства, GND -> GND. Для обычной работы достаточно USB/BLE/Wi-Fi и CAN.

GPIO2, GPIO8 и GPIO9 оставлены свободными: это strap-пины ESP32-C3, поэтому ленту лучше не вешать на них.

## Сборка

Нужен ESP-IDF 5.5.4 и настроенный `IDF_PATH`.

```powershell
idf.py -B build_super_mini_c3 -DIDF_TARGET=esp32c3 -DHW_NAME="NyxExpress" reconfigure
idf.py -B build_super_mini_c3 build
```

Артефакты:

```text
build_super_mini_c3/vesc_light.bin
build_super_mini_c3/bootloader/bootloader.bin
build_super_mini_c3/partition_table/partition-table.bin
```

## Подсветка в прошивке

Для `NyxExpress` подсветка запускается самим firmware-модулем. LispBM и отдельный lighting-пакет для этого не нужны: это важно, потому что ошибки Lisp не могут уронить рендерер или занять его память.

Подсветка и тормозной сигнал находятся в основной конфигурации Express и применяются через обычный `COMM_SET_CUSTOM_CONFIG`. Поэтому одна и та же страница работает и в desktop-, и в mobile-VESC Tool. Старые настройки из namespace `nyxlight` мигрируются при первом запуске новой прошивки.

В обычном VESC Terminal после старта должна появиться строка вида:

```text
NyxLighting: native renderer ready, GPIO10, 150 LEDs, effect 1
```

Для быстрой диагностики доступны команды `nyxlight`, `nyxlight on` и `nyxlight off`.

Старый Lisp-тест ниже оставлен только для универсальной проверки RGB-драйвера на других сборках. Не запускайте его одновременно с firmware-модулем на GPIO10: оба пути будут пытаться управлять одним RMT-каналом.

## Ручной Lisp-тест RGB-драйвера

В VESC Tool откройте LispBM Editor, вставьте `examples/super_mini_c3_ws2812.lisp` и запустите. Для другой длины ленты поменяйте `led-count`. Для одной тестовой ленты минимальная последовательность такая:

```lisp
(rgbled-init 10 1)
(def leds (rgbled-buffer 8 0 1))
(rgbled-color leds 0 (color-make 1.0 0.0 0.0))
(rgbled-update leds 10)
```

Второй аргумент `rgbled-init` со значением `1` выбирает тайминг WS2812B, а тип `0` у `rgbled-buffer` означает порядок GRB.
